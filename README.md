# gionzana · apps

Little apps for everyday things: offline, no account, and your data stays on your phone.

This repo is the front door: one page that lists all my apps, live at **https://rb-gith.github.io/**.

| App | What it does |
|---|---|
| [Sfumato](https://rb-gith.github.io/sfumato/) | Colour wheel and palettes |
| [Tasca](https://rb-gith.github.io/tasca/) | Shop cards in your pocket |
| [Tempo](https://rb-gith.github.io/tempo/) | Hours per project |
| [ELF](https://rb-gith.github.io/elf/) | Gift ideas for every occasion |
| [Spines](https://rb-gith.github.io/spines/) | Your books on a shelf |
| [Habits](https://rb-gith.github.io/habit-tracker_r/) | Daily habits and streaks |
| [Respira](https://rb-gith.github.io/respira/) | Guided breathing |
| [Particle Mahjong](https://rb-gith.github.io/particle_m/) | Mahjong with particle physics tiles |

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole page. To add an app, add one line to `APPS` near the bottom, with its text in English and Italian |
| `wordmark.png` | The gionzana logo |

This page is deliberately not an installable app and has no offline helper (service worker): one at the site's main address would sit over every app.
